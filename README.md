
# EduTrack ML - Student Performance Analyzer

## About the Project
EduTrack ML is a beginner-level Machine Learning project
that analyzes student study hours, attendance, previous
marks and predicts expected final marks.

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
- Joblib

## Dataset
The practice dataset contains 200 synthetically generated
student records with these columns:
- Study_Hours
- Attendance
- Previous_Marks
- Final_Marks

Note: This is synthetic demo data, not real student data.

## Machine Learning
- Linear Regression
- Train-test split
- Model evaluation using MAE, MSE, RMSE and R2 score
- Saving and loading the trained model using Joblib

## How to Run
1. Download or clone this repository.
2. Install the required libraries:

   pip install numpy pandas matplotlib seaborn scikit-learn joblib

3. Open EduTrack_ML.ipynb in Jupyter Notebook.
4. Run the notebook cells.

## Project Files
- EduTrack_ML.ipynb: Project code and analysis
- student_performance.csv: Practice dataset

## Disclaimer
This project is for educational practice only.
Predictions from synthetic data are not validated
for real student performance assessment.
